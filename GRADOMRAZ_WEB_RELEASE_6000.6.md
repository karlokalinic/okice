## Genuine fullscreen

The ColdCity WebGL HTML template now implements:
- Native browser Fullscreen API on the **unity-container**. Not a CSS-only fake fullscreen. Both Unity canvas and exit control are inside the fullscreen element.
- Small PUNI ZASLON / PROZOR toggle; Alt+Enter to toggle; Esc to exit. Browser F11 remains browser-controlled.
- Full bleed, no body margins, zero scrollable overflow, CSS 100dvh and :fullscreen support, safe-area-aware placement.
- Unity WebGL matchWebGLToCanvasSize: true, so the actual WebGL backing buffer resizes as well as the canvas CSS rectangle.

- Clicking PROZOR restores windowed mode.

## Rendering and memory

- Isolated Web URP HDR pipeline, 2x MSAA, 2048/1024 shadow resolutions, 2 cascades, 32m shadow distance, no unused opaque-copy buffer; depth buffer retained for SSAO.
- ACES/cinematic grade, restrained bloom/vignette/grain, adaptive render scale from 0.72 to 0.94, shared Web glass/wet concrete/lit paper shaders.
- **Bloom shader fix confirmed:** Unity 6.6's new serialized URPShaderStrippingSetting previously removed all GLES3 postprocess variants. The Web release builder disables that setting. The actual WebGL compilation now retains Bloom/DoF/UberPost shader variants, and Edge reports **no previous Bloom/DoF/Panini stripped-shader warnings**.
- One remaining nonfatal warning: Edge Adaptive Spatial Upsampling (FSR, shader model 4.5) is unsupported by WebGL GLES3. Do not claim FSR works. A shadowed-light-limit warning also occurs inside gameplay. Neither prevented the tested room from rendering.
- Two console resource 404 lines were observed; none of the 22 filtered Unity player asset requests failed.
- 126 pre-mipmapped textures now stream mipmaps; 10 long audio clips are compressed in memory instead of decoded at import/load. The configured texture streaming budget is 256 MB; actual RAM/GPU usage and FPS were not benchmarked.

## Rebuild and QA

1. Open the project/release branch in Unity 6000.6.9f1 with Web Build Support.
2. Tools → GRADOMRAZ → Web Release → 1 - Stage progressive Web release (or GradomrazWebReleaseBuilder.Stage in headless Editor).
3. Run GradomrazWebReleaseValidator.Validate for canonical scene hashes, menu input bridge, audio/texture importers and shaders.
4. Tools → GRADOMRAZ → Web Release → 2 - Build production WebGL (GradomrazWebReleaseBuilder.BuildRelease).
5. Serve Builds/GRADOMRAZ-Web6 over HTTP with correct Content-Encoding: br on every .br resource and application/wasm for WASM. Do not open by file://.
6. Re-run fullscreen, startup, NOVA IGRA and 30-second gameplay smoke tests before promoting to production.
